# Utilitree

Little tools that live on the edge of your screen. The first one, **Token
Maxing**, shows how close your coding agents are to their limits.

**Download:** https://utilitree.vercel.app

This repository holds release files only. Utilitree is free to use and closed
source; see the LICENSE included with each download.

Every release lists SHA-256 hashes in `SHA256SUMS.txt`.
